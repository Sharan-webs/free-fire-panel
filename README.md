# FF Headshot Aimbot

## How to Build (No PC Needed)

1. Fork this repo on GitHub
2. Go to Actions tab → Enable Actions
3. Push any change or click "Run workflow"
4. Download APK from Actions → Artifacts

## How to Install
1. Enable Unknown Sources on phone
2. Install the APK
3. Open app → Grant Overlay Permission
4. Press START → FF launches automatically
5. Draggable menu appears in corner
6. Toggle HEADSHOT button ON/OFF
7. Press X to hide menu

## Requirements
- Android 5.0+
- Free Fire installed
- Overlay permission granted

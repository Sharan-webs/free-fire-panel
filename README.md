# FF Headshot Panel

## Build (No Laptop Needed)
1. Install GitHub app on phone
2. Create new repo: ff-headshot-panel
3. Upload ALL files maintaining folder structure
4. Go to Actions tab — build triggers automatically
5. Wait 3-5 min → download artifact → install APK

## How it Works
- Permission page grants: Overlay, PIP, Accessibility, Usage Stats, Shizuku
- START button launches Free Fire + overlay service
- Floating "FF" button appears on screen (draggable)
- Tap it → mod menu opens
- Toggle "Headshot Only" ON
- Accessibility service injects taps at head-zone (28% Y from top)
- ✕ closes menu, ■ stops panel entirely

## Packages Supported
- com.dts.freefireth (FF Global)
- com.dts.freefiremax (FF MAX)
